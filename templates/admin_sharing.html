Some challenges give every {{ 'team' if teams_mode else 'player' }} or connection its own flag: an instancer, or a remote service that prints a random suffix accepted by a regex flag (for example flag\{some_string_[0-9a-f]{16}\}). On those, the same flag coming from two {{ 'teams' if teams_mode else 'players' }} means it was passed between them.

Only watched challenges are checked: with a normal static flag, everyone submits the same string. Every submission is compared, accepted or not, so a flag that belongs to another team's instance is caught even when CTFd rejects it.
